Introduction

MLscript is an object-oriented and functional programming language with records, generic classes, mix-in traits, first-class unions and intersections, instance matching, and ML-style principal type inference. These features can be used to implement expressive class hierarchies as well as extensible sums and products.

Values

MLscript has a set of common primitive values.

0 // Integers
3.14159 // Real numbers
true // Boolean
"this is a string" // String
[true, false] // Tuples

You can use common operators in JavaScript to build expressions.

1 + 2 // 3
1 + 2 * 3 - 4 // 3
"hello" === "world" // false
false || true // true
1 < 2 && 3 > 2 // true
!false // true
2 ** 3 // 8

Expressions can be bound to variables via let declarations.

let x = 1
let y = 2
let z = x + y // 3

Functions

Functions can be defined by fun keyword. Parameters need to be enclosed in parentheses.

fun id(x) = x
id("hello") // "hello"
fun sum(x, y) = x + y
sum(40, 2) // 42

In particular, we support using the `of` operator to call functions without parentheses.

id of "hello" // "hello"
sum of 40, 2 // 42

Lambda functions are also supported.

x => x
(x, y) => x + y

Local functions can also be written in the form using let.

let sum(x, y) = x + y
sum(40, 2) // 42

The types of functions are automatically inferred. But you can also specify the types explicitly. Type parameters are enclosed in square brackets.

fun id[A](x: A): A = x

Classes

We can define classes. For example, the following is a class definition for a simple Point class. It has two parameters x and y of type Int.

class Point(x: Int, y: Int)

To make parameters accessible by property access .. We have to declare them with val.

class Point(val x: Int, val y: Int)
let origin = Point(0, 0)
origin.x + origin.y // 0

If all the class parameters are accessible, we can use the data modifier instead.

data class Point(x: Int, y: Int)

We can also define classes with type parameters.

class Pair[A, B](val first: A, val second: B)

The methods of a class are placed in the block that follows `with`.

class Point(x: Int, y: Int) with
  fun distanceToOrigin() = Math.sqrt(x ** 2 + y ** 2)

Extending Classes

Classes can be extended with extends keyword. Here is the definition of Option type in MLscript, which is very common in provided examples.

abstract class Option[out T]
class Some[out T](value: T) extends Option[T]
object None extends Option[nothing]
  • Class Option is abstract and has two sub-classes, Some and None.
  • The : (Some[T] | None) clause indicates that type Option[T] only has two possible subtypes: Some[T] and None.
  • The type parameter T is marked as out to indicate that it is covariant.
  • module keyword is used to define a singleton object. Here, None can be either used as a value or a type.

Algebraic Data Types

The above Option type forms an ADT, and it can also be defined with the constructor keyword.

abstract class Option[out T]
constructor
  Some(value: T)
  None

Similarly, we can define the List type.

class List[out T] with
  constructor
    Cons(val head: T, val tail: List[T])
    Nil

We can define a list of three integers as follows.

Cons(0, Cons(1, Cons(2, Nil)))

To construct lists just like in other functional languages, we can define the concatenation operator ::.

fun (::) cons(x, xs) = Cons(x, xs)

Then we can construct the same list as follows.

0 :: 1 :: 2 :: Nil

The List type is a common data structure in examples.

Pattern Matching

We can define many functions that operate on lists. For example, we can define a function that sum all elements in a list.

fun sum(xs) = if xs is
  Nil then 0
  Cons(x, xs') then x + sum(xs')
